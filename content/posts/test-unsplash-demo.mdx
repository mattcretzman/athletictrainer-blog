# Test Post

This is a demonstration post showing the Unsplash auto-fetch feature in action.

The `featuredImage` is set to `"auto"`, so the system will:
1. Query Unsplash API with "military fitness training facility" (category query)
2. Download the best matching professional photo
3. Save it to `public/images/blog/test-unsplash-demo-unsplash.jpg`
4. Update this frontmatter with the path and attribution
